Dashboard Build Guide

Thirty-four reports across six dashboards, built by hand in HubSpot. Every field named here exists in the portal and is populated — nothing below needs new data.

TIER

Check this before you start

The portal is accountType: STANDARD — a free account. Free tier gives you the standard report library; the custom report builder is Professional+. Open Reporting → Reports → Create report and see whether "Custom Report Builder" is offered. If it is not, build what you can from "Singular object" reports, which still cover most of the list below, and say plainly in the interview which reports need Professional. Naming the constraint is a stronger answer than pretending it isn't there.

How to

Creating a dashboard

  1. Go to Reporting → Dashboards → Create dashboard.
  2. Choose Start from scratch — the templates assume a standard sales motion and won't match a two-sided delivery business.
  3. Name it, set visibility to Everyone, and create.
  4. Inside the dashboard: Add report → Create custom report → Singular object, then pick the object named in each spec below.
  5. Set the chart type, drag the named field to the X axis, set the measure, then add the filters exactly as listed.
  6. Save and add to the dashboard.

Dashboard 05

Win rate diagnostics

Why 30.1% is 30.1%. Every report here is a single-object Deals report, so the whole dashboard works on the free tier — which is only true because WF-09 mirrors the buyer’s grade, score and territory onto the deal. Left on the contact, the two most valuable cuts would need the Professional custom report builder.

READ

How to read a win rate on the free tier

HubSpot’s standard reports do not compute a ratio. Build each of these as a count of Deals split by Deal stage, stacked on the dimension named — then read won against won+lost off the chart. Filter Placement Status is unknown on every one, or delivery engagements (all Closed Won) will inflate each bar.

Careful

Four traps

TrapWhat happensDo this
Win rate All 500 delivery engagements are Closed Won, so an unfiltered win rate reads ~59% instead of the real 30.1% Always filter Placement Status is unknown on any sales metric
Create Date HubSpot makes createdate immutable after creation, so every company shows today Report on Client Since instead — it was built for exactly this reason
Service Type Semicolon-separated text, so counts exceed the number of deals Describe it as "requests", not "deals", and say so before you're asked
Lifecycle Stage HubSpot only ever moves it forward. A write that moves a contact backwards returns 200 and silently does nothing, so a lifecycle report can show stages the data no longer supports To move one back, set the property to empty first, then set the target value. Two writes, never one
